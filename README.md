# strong_encryption​
基于 C++ 与 libsodium 的高性能加解密与密钥派生工具集

项目简介
本项目是一个使用 C++ 结合 libsodium 库实现的高性能、安全可靠的加解密与密钥派生工具集。旨在提供工业级的密码学原语封装，兼顾运行效率与内存安全性，适用于对数据安全和性能有极高要求的场景。

核心功能模块
CRYPTO::XChaCha20Poly1305 类

提供强大的 XChaCha20-Poly1305 认证加密（AEAD）与解密功能。

集成 Argon2id 算法，实现安全可靠的密钥派生流程。

Argon2id 类

专为密码哈希与二进制密钥派生设计。

支持敏感数据的底层内存锁定与安全擦除，有效防止内存侧信道攻击。

编译与构建产物

包含针对特定平台优化的编译后二进制及 PE 文件结构，开箱即用。

依赖项
C++ 标准库：要求支持 C++17 或更高版本。

libsodium：现代、易用的密码学库，提供核心的加解密算法支持。
